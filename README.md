# Meus Sites Favoritos

Projeto desenvolvido em HTML para a disciplina de Desenvolvimento Web.

## Descrição
Esta página web apresenta meus 5 sites favoritos com:
- Nome do site;
- Imagem do site;
- Link para acesso.

## Sites utilizados
- Instagram
- YouTube
- WhatsApp
- Fiel Torcedor
- Snapchat

## Tecnologias utilizadas
- HTML5

## Estrutura do projeto
A pasta do projeto contém:
- `index.html`
- Imagens dos sites
- Captura de tela do código
- Captura de tela da página no navegador

## Como executar
1. Baixe os arquivos do projeto;
2. Abra o arquivo `index.html` no navegador.
